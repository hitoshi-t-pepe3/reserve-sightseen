# 旅行プラン PWA × Bitchat 統合 - 実装要件書

> ユーザー提供のスペック（2026-07-14 受領・全文）
> 実装メモ: 秘密鍵は「PWA生成 + IndexedDB 暗号化保存」方式を採用（ユーザー了承済み）。
>
> **実装時の訂正（Bitchat 実機で互換確認済み）:**
> - イベントは **kind 1 ではなく kind 20000（ephemeral）**。Bitchat の実装に合わせた
> - タグは `["g", geohash6]` + `["n", ニックネーム]`。送信時に NIP-13 PoW（8bit）を付与
> - リレーは固定3つではなく、**permissionlesstech/georelays の CSV からチャンネル座標に近い5件**を選ぶ
>   （kind 20000 はリレーに保存されないため、Bitchat と同じリレーに繋がないと届かない）
> - ジオハッシュ例「(34.76,135.75)→wy76ej」は誤り。正しくは xn0t9p（参照実装と照合済み）

## 概要
既存の旅行プラン作成 PWA に、Bitchat の位置情報チャット機能を統合
- Nostr Relay を経由したリアルタイム位置ベースチャット
- PWA 内でインライン表示・管理

---

## 機能要件

### 1. 位置情報チャット機能
- **精度**: ブロック単位（6文字ジオハッシュ）～1km²
- **対象**: 旅行プランの各地点
- **リアルタイム**: WebSocket 経由で新着メッセージをリッスン
- **相互配信**: Bitchat ユーザーとメッセージ共有可能

### 2. チャット表示
- 旅行地点をクリック → その場所のチャンネルに自動切り替え
- チャットパネルをPWAに埋め込み表示
- 過去メッセージ: 不要（リアルタイムメッセージのみ表示）
- メッセージローカル保存: 不要（一時的に表示のみ）

### 3. メッセージ送受信
- テキストメッセージのみ
- 署名: Nostr の秘密鍵で暗号化署名
- 送信後: Nostr Relay に配信 → Bitchat ユーザーに即座に表示

### 4. ON/OFF トグル機能
- **目的**: バッテリー・ネットワーク負荷軽減
- **配置**: ヘッダーまたは設定に ON/OFF スイッチ
- **OFF状態**: Nostr Relay 接続を切断、チャットパネル非表示
- **ON状態**: Relay リッスン開始、チャットパネル表示
- **状態保持**: LocalStorage に設定を保存して次回起動時に復元

### 5. スパム対策（ユーザーブロック）
- **ブロック方式**: ユーザーの Nostr 公開鍵でブロック
- **UI**: メッセージ横にブロックボタン
- **機能**: ブロック済みユーザーのメッセージは表示しない
- **永続化**: IndexedDB にブロックリスト保存
- **解除**: ブロック管理画面からブロック解除可能

## 技術仕様

### Nostr Relay
- **ライブラリ**: `nostr-tools`
- **複数リレー接続**:
  - `wss://relay.damus.io`
  - `wss://nos.lol`
  - `wss://relay.snort.social`
- **イベントタイプ**: Kind 1（テキストノート）
- **タグ**: `["g", "ジオハッシュ"]`

### ジオハッシュ
```javascript
// 例：京都駅 (34.76, 135.75)
geohash(34.76, 135.75, precision=6)
// → "wy76ej" （～1km²）
```

### ローカルストレージ
- `localStorage`: チャット ON/OFF 状態
- `IndexedDB`: ブロックリスト（公開鍵のセット）

## データモデル

### メッセージイベント
```javascript
{
  kind: 1,
  content: "メッセージテキスト",
  pubkey: "ユーザーの公開鍵",
  created_at: UnixTimestamp,
  tags: [
    ["g", "wy76ej"]  // ジオハッシュ
  ]
}
```

### ブロックリスト
```javascript
{
  id: "pubkey_string",
  blockedAt: Timestamp
}
```

## パフォーマンス目標
- **オンメモリ**: Relay 接続時のメモリ使用量は最小限
- **バッテリー**: OFF 時はほぼ消費なし
- **ネットワーク**: 複数リレーは必要に応じて絞れるように

---

## セキュリティ・プライバシー
- ユーザー秘密鍵は **PWA に保存しない**（Bitchat アプリから来たユーザーのみ署名可能な設計）
  - または、PWA が秘密鍵を生成・管理する場合は IndexedDB で暗号化保存 ← **採用**
- ジオハッシュは **6文字（ブロック単位）** → 正確な位置は露出しない
- メッセージ送信時のみ Relay と通信
