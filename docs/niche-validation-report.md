## 調査B: 競合のツール化状況（完了）

### 調査の目的

戦略ドキュメント §1 の原則に基づく:

> **ボリュームが大きい領域ほど、既に同じ手法の専業サイトが存在する。**
> したがって「ボリュームを狙う」だけでは不十分で、**「ボリュームがそこそこ × 型番/互換という参入障壁 × まだツール化されていない」**の三条件で選ぶ。

各ジャンルについて、①上位が静的記事か自動更新ツールか ②1本あたり単価をリアルタイム計算しているか ③価格推移（履歴）を持つか ④対応表と価格比較が統合されているか、を調べた。

### 結果

| ジャンル | 対応表の所在 | 単価計算 | 価格推移 | 統合状況 | 判定 |
|---|---|---|---|---|---|
| **カミソリ替刃** | 静的記事のみ | ✕ | ✕ | ✕ 分断 | **◎ 空いている** |
| **電動歯ブラシ替えブラシ** | 静的記事 + メーカー公式 | ✕ | ✕ | ✕ 分断 | **◎ 空いている** |
| **空気清浄機フィルター** | 互換品ショップの分類ページ + 個人ブログ | ✕ | ✕ | ✕ 分断 | **◎ 空いている（独自軸あり・後述）** |
| **浄水器カートリッジ** | 静的な品番一覧 + 比較記事 | △ 記事内の言及のみ | ✕ | ✕ 分断 | ○ 空いている |
| **掃除機紙パック** | メーカー公式・PDF が豊富 | ✕ | ✕ | ✕ 分断 | △ 安全性の懸念あり（後述） |
| （参考）おむつ | — | **◎ 専業3サイトが毎日更新** | 不明 | ◎ 統合済み | **✕ 除外** |

### 中核の結論

**候補5ジャンルすべてにおいて「対応表 × リアルタイム価格 × 1本あたり単価 × 価格推移」を統合したサイトは存在しない。**

構造はどのジャンルも同じで、**きれいに分断されている**:
- 対応表 → 個人ブログの静的記事、またはメーカー公式（価格情報なし）
- 価格比較 → 価格.com / Yahoo!ショッピング（互換マッピングなし、単価計算なし）
- 互換品の情報 → 販売ショップの商品ページ（中立的な比較ではない）

カミソリ替刃・電動歯ブラシ替えブラシについては、検索エンジンが明示的に「自動更新で価格推移を比較する専門サイトの情報は含まれていません」と回答した。**この統合が本サイトの取るポジション。**

### 除外判断: おむつ

当初は有力候補だった（検索ボリューム巨大 + 円/枚の正規化はツールの得意技）。**しかし「1枚あたり単価を毎日自動更新で比較する専業サイト」が既に複数存在した:**

- [hula-la.com](https://hula-la.com/diaper.html) — オムツ1枚あたりの最安値・ブランド別単価表
- [babybestmarket.com](https://babybestmarket.com/variation_items/diaper) — 1枚あたりの価格比較（毎日更新）
- [kuchikomitree.com](https://kuchikomitree.com/baby/day) — 1枚あたりの単価を毎日チェック

**本計画が採ろうとしていた手法そのもので、しかも先行している。**後発で同じ武器では戦えないため除外。

> この1件が調査Bを必須工程とした根拠。**おむつは調査A（実データ計測）だけなら合格していた。**競合のツール化状況を見なければ、正面から負ける戦場に入っていた。

## 調査Bで得られた副次的な発見

### 1. 空気清浄機フィルターに独自の計算軸がある（重要）

複数の情報源で、**純正フィルターの交換目安は10年、互換品は3〜5年**という寿命差が報告されている。

これは本サイトにとって非常に強い差別化材料になる:

- 単純な購入価格比較では **互換品が圧倒的に安く見える**
- しかし**寿命で割った年間コストでは逆転しうる**
- **この計算を誰もやっていない**

戦略ドキュメント §2 の「年間ランニングコスト自動計算」がそのまま刺さる。しかも「安い方を売る」のではなく「実質どちらが得か」を示す形になるため、サイトの信頼性にも寄与する。

→ **空気清浄機フィルターを投入順序 3位 に繰り上げる**（浄水器カートリッジと入れ替え）。グローバルブランド比率が高く §7 の英語展開とも相性が良いことも後押しする。

### 2. 掃除機紙パックは順位を下げるべき

メーカーおよび日本電機工業会が「**非純正の紙パックは本体内部で漏れが生じ、発煙・発火につながるおそれがある**」と明示的に警告している。

本サイトの構造は「純正 vs 互換の価格差を示す」ものなので、このジャンルでは**互換品を推す形になること自体が無責任**になりうる。収益性より先に、この点で適さない。

→ **投入順序 5位のまま据え置き。着手する場合は「安さ」ではなく「純正の妥当性」を示す構成に変える必要がある。**

### 3. 掃除機紙パックは PDF 抽出の good testbed

一方で、このジャンルは適合表が **PDF で公開されている**（コメリの1989〜2014年 適用機種一覧、日本電機工業会の資料、各メーカー公式）。

`tools/extract-from-pdf.ts` を開発・検証する際の題材として優秀。**サイトとして公開しなくても、パイプライン開発用のサンプルとして使う価値がある。**

## 調査Aが未実行の理由：このリモート環境からは `openapi.rakuten.co.jp` に到達できない

`RAKUTEN_APPLICATION_ID` / `RAKUTEN_AFFILIATE_ID` は入手済み・`backend/.env` に設定済み（`.gitignore` 対象、コミットはされていない）。**しかし Claude Code on the web のこのリモート実行環境は、組織のネットワークポリシーにより `openapi.rakuten.co.jp` へのアウトバウンド通信をブロックしている。**

```
gateway answered 403 to CONNECT (policy denial or upstream failure)
host: openapi.rakuten.co.jp:443
```

これはAPIキーの誤りでもスクリプトの不具合でもなく、**環境のegressポリシーによるもの**。本番の Cloud Run（`backend/app/tools/rakuten_travel.py` が同じホストを叩く構成）では通っているはずだが、この開発用リモート環境では通らない。

**対応: ローカル環境（またはegress制限のないCI）で実行する。**

### 実行手順

```bash
# 1. このブランチを pull（scripts/niche_research.py は Phase 0 で追加済み）
git pull origin claude/affiliate-site-strategy-kl85k3

# 2. 依存関係
pip install httpx

# 3. backend/.env に RAKUTEN_APPLICATION_ID を設定 済み変数を渡す
RAKUTEN_APPLICATION_ID=... python3 scripts/niche_research.py
```

所要 約40秒（31リクエスト × 1.3秒スロットリング）。完了したら `docs/niche-research-raw.json` の生データと、標準出力に出る Markdown 表をこのセッションに貼っていただければ、レポートへの反映と投入順序の確定を行う。

### 調査A 実行時の注意

- 楽天は 1 applicationId につき **1秒1リクエスト**。スクリプトは 1.3 秒間隔で待つ。429 が出たら `THROTTLE_SECONDS` を上げる
- 旧ドメイン `app.rakuten.co.jp` は 2026/5/14 に停止済み。スクリプトは新ドメインの `IchibaItem/Search/20260401` を叩く。**404 が返る場合は楽天のバージョン改定を確認し、`RAKUTEN_ITEM_SEARCH_URL` 環境変数で上書きする**
